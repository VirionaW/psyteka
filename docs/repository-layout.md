## План будущего упорядочивания (без изменений в работающем коде)

| Кандидат на папку | Содержимое | Условие переноса |
| --- | --- | --- |
| `src/core/` | Общая логика сайта, каталога и портфолио | Обновлены все `script src` и программные ссылки |
| `src/methods/` | Скрипты отдельных методик | У каждого файла определены все зависимости и назначенный рабочий чат |
| `styles/core/` | Основные стили, темы, адаптивность | Перепроверены порядок подключения и каскад CSS |
| `styles/methods/` | Стили конкретных методик | Исправлены пути внутри CSS и HTML, проверены карточки и печать |
| `pages/` | Дополнительные страницы | Сохранены публичные URL, внутренние ссылки и маршруты |
| `docs/` | Служебные документы и история | Обновлены все ссылки из AGENTS.md, ТЗ и других документов |

**Ни одна из этих папок сейчас не заменяет рабочие пути.** Это будущая схема, не указание другим чатам немедленно переносить файлы.

## Правила безопасного перемещения файлов

1. Перед любым переносом читать [AGENTS.md](../AGENTS.md), [обязательные правила](technical-specifications/MASTER_RULES.md) и актуальные ТЗ.
2. Не переносить и не удалять модули, с которыми работают другие чаты. Работа в `main` идет параллельно.
3. Проверять ссылки по **всему репозиторию**, включая `script src`, `link href`, `url(...)` в CSS, `fetch(...)`, пути скачивания, Print/Word и ссылки из документации.
4. Делать перенос отдельным небольшим пакетом в отдельной ветке с перечнем файлов. Не заменять одновременно весь каталог, дизайн и диагностики.
5. Проверять работающие страницы, мобильное меню, портфолио, обработку, изображения, стили, бланки и печать. Проверять как минимум прямые URL старых страниц.
6. Сверять основную ветку непосредственно перед объединением, чтобы не перезаписать более новые изменения других чатов.
7. Не удалять старую копию, пока не проверены все обращения и опубликованный сайт. Коммит не равен публикации.
8. Без отдельной проверки сохранять корневые **AGENTS.md, README.md, PORTFOLIO_TZ.md, SITE_TASKS.md и VISUAL_BRIEF.md**: на них ссылаются действующие правила.

**Статус:** создан только безопасный указатель; физическая реорганизация работающих HTML/CSS/JS не выполнялась. Это сделано намеренно, чтобы не сломать «Психотеку» и не помешать другим чатам.
