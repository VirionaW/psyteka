# ТЗ 10. Координация чатов, GitHub и сохранность изменений

**Редакция 1.0, 26.10.2026.** Несколько чатов работают над **одним** репозиторием, но не имеют гарантированной синхронизации контекста.

## Единый источник
Правила – корневой AGENTS.md и ТЗ 01-12. Фактический код – актуальная ветка GitHub. Задачи и назначение – реестр. Методическая достоверность – проверенные источники. Опубликованная версия – результат реального развертывания и просмотра сайта. Не полагаться на пересказ или память другого чата.

## Распределение
Перед выбором методики проверять ID, существующие материалы и исполнителя; не дублировать задачу. По умолчанию одна методика закреплена за одним чатом, разделение на руководство/обработку/изображения – только с четкими границами. При невозможности завершить методику из-за ключа или источника – фиксировать блокировку, продолжать свободную.

## GitHub
Читать последние файлы перед правкой. Желательны небольшие задачи, тематические ветки, осмысленные коммиты и PR; не перезаписывать общий файл старой копией. Конфликт с правками других чатов разрешать с сохранением обеих правильных частей. Для общих компонентов – расширенная регрессия. Никогда не делать принудительный откат, стирающий независимые изменения, без обоснования.

## Передача
Записывать: ID задачи, методику, назначение, измененные файлы, ветку/коммит, сделанное, проверенное, не проверенное, блокеры, следующие действия и применимые ТЗ. Новому чату необходимо открыть актуальную документацию, а не предполагать, что он автоматически знает о прошедших сообщениях.

## Публикация
Коммит ≠ развертывание. До публикации – проверка файлов, расчетов, печати и UI. После публикации – проверить рабочий сайт и нужную версию. Не обещать фоновую разработку, если отдельный механизм не запущен. Не хранить токены и реальные данные обследуемых в репозитории.
