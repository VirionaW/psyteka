# Проверка школьных опросников первого полугодия – 29.10.2026

## Объем
Пять методик: CDI Ковач (27), школьная тревожность Филлипса (58), самооценка состояний Айзенка (40, две редакции), способы совладания Лазаруса (50), ОСР Разуваевой (29).

## Измененные файлы
- `method-class-entry-2026.js` – клавиатура, переход между вопросами, пропуск детей, отметка отсутствия, добавление списка.
- `method-semester-2026.js` – расчеты по четырем методикам, исключение отсутствующих из расчетов, отчеты и CSV.
- `method-phillips.js` – обработка отсутствия в группе и экспорте.
- `experience.js` – связь с портфолио, начальный фокус на первом пустом вопросе.
- `library.html`, `site-semester-2026.css` – подключение и оформление.

## Фактически выполненные автоматические проверки
- JavaScript-синтаксис всех четырех измененных JS-файлов – без ошибок.
- 4 новых калькулятора: минимальные и максимальные значения; неполный ввод не порождает расчет; отсутствующие исключаются из расчетов.
- Филлипс: 58 бинарных ответов, 8 факторов, отсутствие не формирует результат.
- Айзенк: две схемы ключей дают разные правильные результаты на контрольной комбинации; по умолчанию версия 2.
- CSV: проверена одинаковая ширина заголовков и строк, колонка статуса, исключение результатов отсутствующих.
- Эмуляция событий клавиатуры: 2, 0 и 1 записываются, фокус переходит вперед; Backspace удаляет балл; вставка последовательности разносит ответы по номерам; Филлипс 1 = «Да», 0 = «Нет».
- Эмуляция класса: отметка отсутствия не удаляет ученика; переход к следующему; вставка списка с пропуском дублирующих кодов.
- Проверена генерация панели учета присутствия и подсказки клавиатурного ввода.

## Не подтверждено
- **Актуальная площадка – Timeweb (уточнение владельца от 29.10.2026).** GitHub содержит изменения, но актуальный URL и способ деплоя Timeweb неизвестны: выпуск и браузерная проверка еще не подтверждены. Предыдущие проверки домена Render **не относятся** к действующему сайту.
- Полноценный визуальный тест в браузере (desktop/mobile), печать реальных страниц и регрессия всех остальных методик не проводились.
- CDI: автоматический расчет принимает уже закодированные по лицензированному бланку баллы, но не преобразует исходный текст ответов без авторского ключа.
- Универсальные нормативы для несовершеннолетних и диагнозы из числовых результатов не выводятся.
- У версии Айзенка необходимо подтвердить полное совпадение бумажного текста, а не только первых вопросов.

## Ожидаемая приемка на работающем сайте
1. Зайти по коду доступа, открыть пять методик и переключить в «Группа / класс».
2. Вставить 3 условных кода, выбрать первого и нажимать 0-3 (или 0/1 у Филлипса) без мыши.
3. Отметить второго отсутствующим, переключиться на третьего, вернуться к первому.
4. Очистить один заполненный ответ, убедиться в отсутствии старой суммы.
5. Проверить отчет CSV: отсутствие указано отдельной строкой без баллов.
6. Проверить обработку обеих версий Айзенка, скачивание протокола и А4 печать.
7. Проверить темную тему и мобильный экран.
