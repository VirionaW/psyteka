# Психотека: включена регистрация и вход по электронной почте

Дата выпуска: 27.10.2026.

## Выполнено

- Gmail SMTP `psyteka.info@gmail.com` настроен владельцем. Отправка OTP и вход подтверждены пользовательскими скриншотами.
- В `auth-config.js` теперь `registrationEnabled: true`.
- В главной `index.html`: при клике на библиотеку открывается рабочее окно с вводом почты, отправкой одноразового кода, подтверждением, выбором бесплатного пробного доступа.
- `site-library-entry.js`: активная регистрация через `supabase.auth.signInWithOtp({email, options:{shouldCreateUser:true}})`, проверка `verifyOtp({email,token,type:"email"})`. После успешной проверки для обычных участников активируется 48-часовой период `psy_trial_access`; владелец и модераторы входят без ограничения по времени.
- Отключено сообщение «подготовка» и старая кнопка тестовой библиотеки. Состояние ошибок показывается внутри окна.
- Страница `register.html` тоже принимает настоящие коды и ведет после входа к библиотеке.
- Принудительно обновлены ссылки с версиями `auth-config.js` на всех основных страницах, чтобы старые браузерные кеши не держали регистрацию выключенной.
- Таблица `psy_trial_access` защищена RLS: пользователь может начать период один раз и не может изменить `expires_at` или перезапустить доступ.
- Учетные записи по умолчанию не получают роли `owner` и `moderator`; они назначаются только Владельцем на сервере.

## Проверено

- Статическая проверка синтаксиса JavaScript.
- Имитация полного пользовательского пути: ссылка на школьную библиотеку -> модальное окно -> запрос OTP с `shouldCreateUser:true` -> правильный код -> бесплатный период -> библиотека с исходным URL.
- Отдельно проверен уже авторизованный владелец: открывает библиотеку без таймера и покупки.
- Supabase проверка: одна роль owner; обычный клиент не может обновлять роли или время ознакомительного периода.
- Доставка SMTP ранее подтверждена владельцем, но **регистрация второго нового аккаунта на реальном адресе еще требует пользовательской проверки**. Не объявлять ее протестированной до получения соответствующего результата.

## Ограничения и следующие шаги

- Отправка через Gmail SMTP может быть ограничена Google; для роста аудитории стоит перейти на транзакционный провайдер с собственным доменом. Настроить CAPTCHA/антибот и контролировать лимиты писем.
- Заранее проверить страницу Supabase Authentication → URL Configuration: Site URL `https://psyteka.onrender.com`, redirect `https://psyteka.onrender.com/index.html?home=1&entry=1`, а также `https://psyteka.onrender.com/register.html` для отдельной страницы. Вход через шаблон `{{ .Token }}` работает без открытия Magic Link.
- **Внимание:** Render static site не обеспечивает серверное скрытие/защиту библиотечных HTML и файлов. Перед подключением платных подписок перенести материалы в private storage и применять проверку доступа в backend. Нынешний JS gate – не DRM.
- Срок пробного доступа 48 часов, запуск добровольный. Платные тарифы и автосписания не подключены.
