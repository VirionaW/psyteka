# Проверка результата перед словом «Готово»

- [ ] Актуальное ТЗ прочитано, задачи других чатов и текущие файлы сверены.
- [ ] Работа ограничена назначенными компонентами.
- [ ] Название, автор, версия, возраст и методический источник сверены.
- [ ] Руководство содержит полноценную инструкцию и не содержит самостоятельных стимулов.
- [ ] «Без бланка» и «С бланком» различаются правильно, когда бланк предусмотрен.
- [ ] Ученический бланк не содержит ключ; стимулы соответствуют конкретной версии.
- [ ] Печать реально проверена: А4, разрывы, поля, без обрезки и пустых страниц.
- [ ] Карточки одинаковых размеров, изображения правильные, типовые цвета имеют смысл.
- [ ] Меню «Диагностика», «Коррекционная работа», «Школа» раскрывается и сворачивается независимо от панели.
- [ ] Портфолио открывается и закрывается крестиком; нет дополнительной кнопки закрытия и дублирующих ссылок.
- [ ] Кнопка обработки расположена справа, а не по центру.
- [ ] Пустая и частично заполненная обработка оранжевая.
- [ ] Полный допустимый и актуально рассчитанный результат зеленый.
- [ ] При удалении обязательного значения возвращается оранжевый.
- [ ] Для расчетов есть независимые контрольные примеры, включая крайние значения.
- [ ] Изменения не повредили другие методики и общие компоненты.
- [ ] Проверены нужные устройства, поиск, навигация и доступность.
- [ ] Коммит/публикация/проверка сайта отражены как разные этапы.
- [ ] Реестр обновлен, если доступен. В отчете прямо указано непроверенное.
