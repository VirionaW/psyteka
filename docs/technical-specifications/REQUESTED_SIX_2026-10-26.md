## Фактические изменения

- Проверены инструкции, возраст, число пунктов, типы ответов и конкретные источники. Опросник Лускановой и рабочая форма Психотеки на 20 утверждений остались отдельными от Лукьяновой и Орел–Куликовой.
- Для TEIQue-ASF изменена регистрация на 7 пунктов согласия, для Орел–Куликовой – на 5; вывод автоматических «уровней» по неподтвержденным ключам отсутствует.
- Для нескольких редакций предусмотрен выбор до работы; ссылка на исходный бланк следует выбору. ССПМ-2020 нельзя обработать под видом ССПМ-2013.
- URS, профессиональные установки и выбранная ССПМ-2020 показывают оранжевое состояние при неполном вводе, зеленое после полного допустимого расчета; удаление значения снимает готовность. Пробел не принимается за нулевой балл.
- Вкладка «Методика / руководство» имеет цель, инструкцию, процедуру, ключ либо явную границу отсутствия подтвержденного ключа, интерпретацию. Печать «Без бланка» и «С бланком» для применимых регистрационных листов сделана с отдельной страницей. Для ССПМ-2020 бланк дополняется только при выборе данной редакции.
- Вкладка «Бланк» содержит регистрационный лист без ключа либо ссылку на нужный оригинальный бланк. Полный защищенный авторский стимульный текст не реконструируется.
- Не добавлялись повторные кнопки на карточки, фиктивные нормы, дополнительные вкладки и дубли методик. Общий компонент печати изменен только условием для `verifiedSix`.
- Все шесть методик имеют отдельные иллюстрации каталога, отличные от диагностических стимулов; кеш версий `library.html` обновлен.

## Проверка

- **47 из 47** программных проверок пройдены на исходном модуле после изменений: конфигурации 6 методик, наличие 3 разделов и 4 обязательных блоков руководства, ссылки, типы ответов, запреты ложной готовности, печатная структура А4.
- URS: все единицы -> [11,6,8], все пятерки -> [55,30,40]; неполные/нулевые ответы дают отсутствие расчета.
- Профессиональные установки: все единицы -> [16,8], все шестерки -> [96,48]; уровни из приложения PDF определяются по указанным границам.
- ССПМ-2020: все единицы -> [12,16,8,12,4,20,4,76], все пятерки -> [12,8,16,12,20,4,20,92]. Последняя цифра – сумма 7 шкал. Пропуск или выбор другой редакции блокирует количественную интерпретацию.
- Синтаксис загружаемого модуля и `experience.js` дополнительно проверен; это **не** эквивалентно визуальной приемке на телефоне, планшете и компьютере.
- **Не проверено:** фактическое развертывание Render, все печатные листы глазами, открытие Word (локальных DOCX для этих версий пока нет), реальный клик по всем действиям в браузере с опубликованным сайтом.
