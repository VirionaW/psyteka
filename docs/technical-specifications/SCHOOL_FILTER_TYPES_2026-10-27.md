# Фильтр способов проведения в Школе · 27.10.2026

## Задача
Раньше пункт «Проективные методики» включал рисуночные, а «Диагностические пробы» включали графические. Отдельных вариантов для рисуночных и графических не было. Это мешало найти нужный способ обследования.

## Исправлено
В `library.html` список `#format` теперь содержит восемь независимых вариантов в двух визуальных группах:

| ID | Отображаемый пункт | Карточек в текущем каталоге |
|---|---|---:|
| drawing | Рисуночные методики | 5 |
| graphic | Графические методики | 5 |
| projective | Другие проективные | 9 |
| questionnaire | Опросники и анкеты | 44 |
| test | Пробы и тесты | 15 |
| interview | Беседы и наблюдение | 3 |
| sociometry | Социометрия | 1 |
| program | Программы и подборки | 18 |
| **Все** | **Все виды методик** | **100** |

Принцип: **одна карточка в одной основной группе**. Классификация описывает способ выполнения, а не психологическую школу или диагностическую цель. Поэтому рисуночная диагностика может быть проективной, но для фильтра относится к «Рисуночным».

Разграничение на примерах:
- «Школа зверей», «Что мне нравится в школе», три семейных рисунка – рисуночные (испытуемый создает рисунок).
- «Лесенка», Дембо – Рубинштейн, «Семейная социограмма», «Графический диктант», копирование фигур Бендера – графические (отметки, линии, символы, копирование).
- «Дерево», Hand Test, детские рисунки-ситуации в тесте фрустрации Розенцвейга, МД-решетка, цветовые ассоциации и незаконченные предложения – другие проективные (стимулы/ситуации предъявляются, не создается свободный рисунок).

## Техническая реализация
- `site-school-cards.js` – метод `PSY_SCHOOL_CARDS.classify()` и список `kindOptions` становятся единым источником классов.
- `experience.js` – школьный список фильтруется по `classify()===state.format`, а не по пересекающимся регулярным выражениям.
- `app.js` – первоначальный рендер использует ту же функцию, обновляет подсветку меню при смене вида; сброс фильтров и поиск остаются.
- `library.html` – явные варианты с `optgroup`, прежние значения «Проективная» и «Проба» удалены из `#format`; обновлены версии JS против старого кеша.
- `site-school-type-filter.css` – удобная ширина селектора на компьютере и 100% ширины на узком экране, только внутри Школы.

## Программная проверка
- Структура каталога: 100 карточек, каждое ID уникально.
- Восемь фильтров: сумма размеров **100**, пересечений нет, ни одна карточка не потеряна.
- Рендер: по всем фильтрам ровно одна кнопка «Открыть методику», три информационные плашки.
- Выбор «Графические» + поиск «Лесенка» дает ровно одну карточку; «Графические» + «Школа зверей» – ноль.
- Значения и подписи пунктов HTML совпадают с классификатором. «Все виды методик» возвращает 100 записей. Скрипты синтаксически проходят проверку.
- **Не проверено**: внешний Render, реальный браузер и адаптивность на устройстве. Изменения внесены в GitHub; публикацию и визуальную приемку нельзя считать подтвержденными.

Ключи, стимулы, возрастные версии, портфолио и ID методик не изменены.
