# Психотека

Профессиональная библиотека психологических методик, бланков и материалов сопровождения.

## Как найти нужные файлы

- [Указатель по страницам, методикам, скриптам, стилям и папкам](docs/repository-layout.md) – подробная карта репозитория с ссылками.
- [Правила для всех рабочих чатов](AGENTS.md) и [ТЗ 01-12](docs/technical-specifications/README.md).

Рабочие файлы пока остаются на прежних местах: перенос без проверки зависимостей может нарушить сайт и работу других чатов.

## Статус разработки
Начат постепенный перенос проекта из автономных ZIP-архивов в онлайн-версию. На первом этапе добавлены отдельная главная с демонстрационным входом, цветовые темы школы, детского сада, взрослых и ОВЗ, профиль и навигация. Полный набор методик, Word-файлов и аналитических инструментов из архива еще не перенесен.

Код тестера для демонстрации: PSY-2026. Этот код не является настоящей защитой сайта.

Не используйте демонстрацию для хранения персональных данных детей. Для психодиагностики проверяйте оригинальный источник, возрастные нормы и права на воспроизведение методики.
