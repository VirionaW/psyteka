# Безопасность переноса

**В этот публичный репозиторий нельзя загружать** дампы БД, почтовые адреса, результаты и персональные данные детей, SQL-выгрузки с реальными строками, резервные копии, .env, пароли VPS, API secret/service_role keys, SMTP-пароли, JWT/refresh tokens и скриншоты закрытой панели с ключами.

Экспорт проводить только напрямую в зашифрованное хранилище, контролируемое владельцем. После переноса пользовательские учетные записи сохраняются, но потребуется повторно авторизоваться. Не гарантировать сохранение существующих MFA-сессий: MFA тестировать и при необходимости перенастраивать с владельцами учетных записей.

Миграция в российскую локацию не отменяет требований к документации оператора персональных данных и не гарантирует автоматического соответствия законодательству.
