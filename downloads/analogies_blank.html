Простые аналогии — бланк

12 заданий. Выбери один вариант ответа в каждом

Код ученика: __________________ Класс / возраст: ________ Дата: __________

Инструкция: прочитай связь между двумя первыми словами, затем подбери аналогичное слово для третьего из четырёх вариантов. Тренировка: «кошка : котёнок = собака : щенок».

1. Птица : гнездо = пчела : ?
□ А) цветок　　 □ Б) улей　　 □ В) крыло　　 □ Г) луг
2. Художник : кисть = плотник : ?
□ А) молоток　　 □ Б) картина　　 □ В) рама　　 □ Г) краска
3. Холодный : горячий = высокий : ?
□ А) длинный　　 □ Б) ровный　　 □ В) низкий　　 □ Г) большой
4. Дерево : лес = звезда : ?
□ А) телескоп　　 □ Б) вечер　　 □ В) планета　　 □ Г) созвездие
5. Молоток : забивать = ножницы : ?
□ А) шить　　 □ Б) резать　　 □ В) складывать　　 □ Г) красить
6. Книга : страница = поезд : ?
□ А) станция　　 □ Б) дорога　　 □ В) вагон　　 □ Г) билет
7. Молоко : корова = шерсть : ?
□ А) овца　　 □ Б) поле　　 □ В) шарф　　 □ Г) нитка
8. Утро : вечер = начало : ?
□ А) день　　 □ Б) путь　　 □ В) середина　　 □ Г) конец
9. Цветок : лепесток = дерево : ?
□ А) лес　　 □ Б) ветка　　 □ В) земля　　 □ Г) сад
10. Сапог : нога = перчатка : ?
□ А) рука　　 □ Б) шея　　 □ В) ступня　　 □ Г) плечо
11. Учитель : школа = врач : ?
□ А) лекарство　　 □ Б) палата　　 □ В) больница　　 □ Г) термометр
12. Рыба : вода = верблюд : ?
